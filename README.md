## 📌 Project Overview

**Talent Management Platform for Employee Performance and Career Growth** (Talent Sphere) is an enterprise-grade, AI-driven platform designed to streamline employee learning, automate skill assessments, and boost career growth. By integrating **Retrieval-Augmented Generation (RAG)**, **LLM-based exam generation**, **voice-assisted mock interviews**, and **progressive study plan access control**, the platform provides a personalized and interactive learning ecosystem for employees while empowering managers with real-time progress monitoring.

---

## ✨ Key Features & Capabilities

### 🔍 1. RAG-Powered Knowledge Search (Milestone 1)
* **PDF Document Ingestion**: Ingests multi-page learning materials and internal documents.
* **Semantic Chunking & Embeddings**: Converts raw document text into optimized data chunks and neural vector embeddings.
* **ChromaDB Vector Store**: Persists embeddings into ChromaDB for high-speed similarity search.
* **Grounded AI Retrieval**: Answers user questions with accurate context retrieved directly from uploaded documents, citing exact source materials.

### 🤖 2. Dual AI Assistants & Role-Based Portals (Milestone 2)
* **Role-Based Access**: Dedicated **Admin Dashboard** for curriculum management, user creation, and exam publishing; and **User Dashboard** for learners.
* **Interactive AI Chatbot**: 24/7 conversational learning companion for answering domain questions.
* **AI Voice Assistant**: Integrated Speech-to-Text (STT) and Text-to-Speech (TTS) for hands-free voice interactions.
* **Admin Exam Creation via AI**: Admins can generate custom multi-format exams (MCQs, True/False, One-Word, Descriptive) using natural language voice or text commands.

### 📅 3. Structured AI 6-Week Study Plans (Milestone 3)
* **Days 1–4 (Learning Content)**: Daily PDF learning modules covering core domain topics.
* **Day 5 (AI-Generated Exam)**: Weekly assessment exam dynamically generated by LLM based on the week's PDF content.
* **Day 6 (Voice Mock Interview)**: AI Voice Assistant conducts a live mock interview consisting of 3 HR evaluation questions followed by technical domain questions.
* **Progressive Unlock**: Unlocks upcoming days and weeks sequentially upon completing previous milestones.

### 🔒 4. Access Control & RAG Guard (Milestone 4)
* **Automated User Onboarding**: Automatically sends secure login credentials to newly registered users via SMTP integration.
* **PDF Page-Level Tracking**: Monitors real-time reading progress using JavaScript `IntersectionObserver`.
* **Completion Enforcement**: "Mark as Completed" button is strictly enabled only after viewing 100% of the PDF pages.
* **RAG Context Shielding**: Only unlocked PDFs are indexed into the AI Chatbot knowledge base. Locked materials remain protected from unauthorized retrieval.

## 🚀 Getting Started

### Prerequisites
* **Python**: 3.10 or higher
* **Node.js**: v18+ (for Frontend Vite build)
* **Groq API Key**: Obtain an API key from [Groq Console](https://console.groq.com/)

### Installation & Setup

1. **Clone the Repository**
   ```bash
   git clone https://github.com/mrudulasaisreesrigiri/Talent-Sphere.git
   cd Talent-Sphere
   ```

2. **Configure Environment Variables**
   Create a `.env` file in the root directory (or copy `.env.example`):
   ```env
   GROQ_API_KEY="your_groq_api_key_here"
   GROQ_MODEL="openai/gpt-oss-120b"
   SECRET_KEY="your_jwt_secret_key"
   DATABASE_URL="sqlite:///talent_sphere_elevate.db"
   ```

3. **Backend Setup**
   ```bash
   # Create and activate virtual environment
   python -m venv .venv
   .venv\Scripts\activate       # On Windows
   # source .venv/bin/activate  # On Linux/macOS

   # Install dependencies
   pip install -r backend/requirements.txt

   # Initialize Database
   python backend/scripts/init_db.py
   ```

4. **Frontend Setup**
   ```bash
   cd frontend
   npm install
   cd ..
   ```

5. **Run the Application**
   Run the unified application launcher:
   ```bash
   python run.py
   ```
   * **Frontend UI**: `http://localhost:5173`
   * **Backend API**: `http://localhost:8000`
